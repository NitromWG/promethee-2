# Contribuer

Le projet est sous GPL-3.0 seule, sans double licence. Chaque contribution est faite sous certificat d'origine du développeur (https://developercertificate.org) : signer ses commits avec `git commit -s`, ce qui ajoute la ligne `Signed-off-by`.

Une modification n'entre que si la CI est verte sur Linux, Windows et macOS. Toute nouvelle règle ou fonction arrive avec ses tests ; une fonction portée du prototype arrive avec ses cas de référence. Les noms du code, les messages et la documentation sont en français, comme le cahier des charges. Les décisions d'architecture importantes sont écrites dans `docs/adr/`.
